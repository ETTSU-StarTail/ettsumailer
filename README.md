# ettsumailer

RFC に準拠したシンプルで拡張しやすいメーラ作ってみる

## ビルド方法

ビルド方法の詳細は [docs/BUILD.md](docs/BUILD.md) を参照してください。

## 見た目イメージ

- 余計な装飾はなしにモダンな見た目で、メールの確認や執筆に集中できるものとしたい。
- 真っ黒や真っ白を避けたグレースケールに留めた配色で目に優しいものとする。
- 見た目の参考としてキーボードだが HHKB Professional HYBRID Type-S 雪、lofree FLOW

## 使用感イメージ

- 起動したらすぐに画面が表示されて利用できる
- メールをサッと確認して対応できる軽快に利用できる

## 使用する技術

- Rust
- Tauri
  - HTML/CSS/JS

Tauri 上で表示する Web 画面にはフロントエンドフレームワークは利用しない。

## 実装する機能

- POP3/IMAP を利用したメールサーバ経由のメール受信
- SMTP を利用したメールサーバ経由のメール送信
- 受信したメールの一覧及び閲覧
- 送信したメールの一覧及び閲覧
- メールのカテゴライズ
- メールのフィルタリング
- **スター/フラグ付与**で重要メールを即座に抽出・表示切替
- **検索機能**で特定ワード・送信者を素早く検索
- **メール→TODO化**で返信漏れ・対応漏れを防止
- **VIP 送信者通知**で重要メールを即座に認識
- **優先キャッチアップ（Must-Read）**で読むべきメールを優先表示（ドメイン＆ルールベース）

## HTMLメール表示ポリシー（メモ）

- HTML メールは「画像読み込みを許可、スクリプト実行は無効化」の方針で表示する。
- `a` タグは有効化し、クリック時はアプリ内遷移ではなく既定ブラウザで開く。
- JavaScript 依存の装飾・計測・トラッキングは表示互換性より安全性を優先して抑止する。
