== 概要

本ドキュメントは ettsumailer のプロダクト仕様を機能観点で整理するための骨子である。
詳細なプロトコル仕様（SMTP/IMAP）は個別仕様を参照し、本書ではユーザー体験とアプリ挙動を定義する。

設計思想として「Less, but better（より少なく、しかしより良く）」を採用し、
機能追加時は「読むべきメールへ最短で到達できるか」を判断基準とする。

関連文書:

* コンセプト: `docs/concept.adoc`
* SMTP仕様: `docs/smtp-specification.md`
* ビルド手順: `docs/BUILD.md`

== スコープ

=== 対象

* メールアカウント設定（IMAP/SMTP）
* メール一覧取得・表示
* メール本文表示（テキスト/HTML）
* メール送信（将来拡張含む）

=== スコープ外（現段階）

* カレンダー/タスク統合
* 組織向け管理機能
* スクリプト依存 HTML 表現の完全互換

== 画面仕様（ハイレベル）

=== サイドバー

* フォルダ一覧（Inbox / Sent / Drafts / Trash）を表示
* 設定ボタンを提供

=== メール一覧

* 送信者、件名、日付、既読/未読を表示
* ページネーションで分割表示（既定: 100件/ページ）

=== メール本文

* ヘッダ情報（From/To/CC/Date/Subject）を表示
* テキスト表示と HTML 表示を切り替え可能（HTMLが存在する場合）
* 外部リンクは既定ブラウザで開く

=== 設定モーダル

* IMAP / SMTP の接続情報を編集
* パスワードは OS ネイティブ資格情報ストアへ保存

== 機能要件

=== 設定管理

* 接続先ホスト、ポート、ユーザー名を保存できる
* パスワードは平文ファイルへ保存しない

=== 受信一覧取得

* IMAP から受信一覧を取得できる
* 取得失敗時はユーザーにエラー理由を提示

=== 本文表示

* プレーンテキスト本文を表示できる
* HTML本文は安全側のポリシーで表示する
** 画像読み込みは許可（http/https/data/blob）
** スクリプト実行は無効
** 危険な属性・URLスキームは除去

=== 優先キャッチアップ（Must-Read）

* 最初に読むべきメールを優先表示できること
* 優先度判定は、頻繁に送受信しているドメイン情報を利用できること
* ルールベース（仕分け規則）で優先対象を抽出できること
* 優先対象のみを先に確認できる導線（表示切替/絞り込み）を提供すること

NOTE: 本機能の名称は暫定。現時点での `Compose` は「送信作成」を指す画面/機能として扱い、
優先キャッチアップとは別機能として整理する。

=== リンク遷移

* `http(s)` / `mailto` のみ許可
* アプリ内 WebView 遷移は行わず既定ブラウザへ委譲

=== 送信

* SMTP でメール送信可能（基本フロー）
* エラー時は再試行可否を含むメッセージを表示

== 非機能要件

=== セキュリティ

* 資格情報は OS キーストア利用
* HTML 表示時の実行コンテンツ抑止
* 入力値検証と fail-fast を徹底

=== パフォーマンス

* 一覧表示はページング前提でレスポンスを維持
* レイアウト負荷を抑える CSS 設計（contain/content-visibility）

=== 可用性

* サーバ接続失敗時の復帰手順を用意
* 設定未完了時のガイド表示を行う

=== アクセシビリティ

* ランドマーク要素に適切なラベルを付与
* キーボード操作で主要導線を辿れること

== データ仕様（概要）

=== EmailSummary

* `uid`, `from`, `subject`, `date`, `unread`

=== FetchResult

* `emails`, `total`, `page`, `total_pages`

=== EmailBody

* `from`, `to`, `cc`, `subject`, `date`, `text_body`, `html_body`

== エラー処理方針

* 通信エラー: 原因を簡潔に表示し、再試行導線を提供
* 認証エラー: 資格情報再設定を促す
* パース失敗: 可能な形式（テキスト）へフォールバック

== 今後の拡張候補

=== 次Phase

* **スター / フラグ機能**: 重要メールを★で抽出・フィルタ表示
* **検索機能実装**: ローカルインデックス模索可能
* **Must-Read優先キャッチアップ**: ドメイン・ルールベースで重要送信者先制
* **VIP送信者通知**: 重要メール到着時に通知警告

=== For Future

* **メール → TODO化**: 返信必須メールをタスク化して追跡、優先キャッチアップモードで警告
* `cid:` 画像の表示対応
* 送信時テンプレートと署名管理
* ログ/診断情報エクスポート

== 更新ルール

* 仕様変更時は本書を更新し、関連コミット/PRへリンクする
* 実装先行で乖離が出た場合は、最短で本書に追記して差分を可視化する
